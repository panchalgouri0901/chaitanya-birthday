CHAITANYA'S BIRTHDAY WEBSITE

FILES
- index.html: complete website (HTML, CSS, JavaScript)
- assets/: the first 8 uploaded photos used in the gallery

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome or Edge. Internet is needed for the Google Fonts; all main functionality works without them.

PUBLISH ON GITHUB PAGES
1. Create a new public repository on GitHub, e.g. chaitanya-birthday.
2. Upload index.html and the entire assets folder (not just the HTML file).
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch; choose main and /(root), then Save.
5. Wait for the deployment and use the URL GitHub Pages displays, typically https://YOUR-USERNAME.github.io/chaitanya-birthday/.

COUNTDOWN
The timer targets 15 October 2026 at 00:00 India Standard Time (+05:30). Before midnight, it displays the countdown. After the target time, it automatically switches to the birthday reveal. The requested date label remains 14TH OCTOBER 2026 on the countdown screen.

UPDATED: Gallery uses 8 photos. Birthday reveal targets 15 October 2026 at 00:00 IST and launches a confetti burst, balloons, floating hashtags, and rising emojis. Keep index.html and assets/ together.
